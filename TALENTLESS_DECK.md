# Talentless Deck

## Description

At the start of each run, the Talentless Deck randomly becomes one of the 15 vanilla Balatro decks. Every vanilla deck has an equal 1-in-15 chance.

The selected deck's normal base effect is copied for the entire run, but all Deck Talents and Global Talents are disabled.

## Possible rolls

- Red Deck
- Blue Deck
- Yellow Deck
- Green Deck
- Black Deck
- Magic Deck
- Nebula Deck
- Ghost Deck
- Abandoned Deck
- Checkered Deck
- Zodiac Deck
- Painted Deck
- Anaglyph Deck
- Plasma Deck
- Erratic Deck

## Talent rules

The following are disabled during a Talentless run:

- All 225 deck-specific talent effects
- All 20 Global gameplay talent effects
- All 10 Global cosmetic talent effects
- Talent-granted Chips, Mult, XMult, money, hands, discards, slots, Tags, and announcements

Boss Blind victories and skipped Small or Big Blinds each award one shared Talent Point, allowing Talentless runs to contribute to permanent progression without enabling permanent talent effects during the run.

## Interface

The Talentless Deck has no tree. Pressing the Talent button while it is selected opens a rules panel explaining the mode. The copied deck is announced when the first Blind begins.

Talent Shop purchases are separate run items and continue to work while using Talentless.
